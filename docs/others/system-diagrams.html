SempreIoT Mesh Map

SempreIoT — how the network is set up and how it runs

Seven pictures, in the order things happen on a site: what the pieces are, how each unit receives the code, every setup case on one map, the states a unit passes through, how the mesh forms by itself, what happens when the root dies, and the path an alarm takes. Vocabulary is the blueprint's: board, AC device, battery detector, the code.

1. The pieces and who talks to whom

board / access point Wi-Fi, Mesh-Lite ESP-NOW USB

2. Configuration — how the code reaches every unit (Case A, installer first)

Every unit, board included, is set up the same way. The phone needs no internet and never opens the Wi-Fi settings screen; it joins the unit's setup network by itself using the sticker secret as the password.

2b. Device setup — every case on one map

Whatever the order on site, the per-unit steps are identical. The only decisions are where the code comes from and what happens to the unit after it has the code.

3. Power-on — the mesh forms itself

Nobody chooses the root. The board raises the installation Wi-Fi; every AC device that holds the code looks for it; Mesh-Lite keeps the best-placed one as root and hangs the rest under it. Detectors find a parent on their next wake.

4. The root dies — and nothing has to be done

5. An alarm, hop by hop

What never changes

The board raises the installation Wi-Fi; the tablet never does. The board is never the root.

Root-capable means "on AC". Battery detectors are always the ones whispering, never relaying.

Every unit — board included — gets the code the same way: sticker, phone joins its setup network, code pushed.

The tablet learns the code from the board over USB; no camera, no internet, no customer router anywhere in the fire path.
